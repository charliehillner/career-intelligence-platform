## GitHub LaTeX Conventions

To ensure consistent rendering on GitHub:

- Prefer `\text{...}` over `\operatorname{...}`.
- Use `\lbrace` and `\rbrace` for curly braces.
- Use `$$ ... $$` for display mathematics instead of `\[ ... \]`.
- Keep `=` on the same line as the preceding expression where possible.
- Verify mathematical notation on GitHub after introducing new LaTeX constructs.
